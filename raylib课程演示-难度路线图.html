raylib 课程演示 · 按难度进阶路线图

难度从低到高共 6 级（★1 → ★★★★★★）。已做的 3 个演示（drawLineEx / drawCircleV / drawRectangleRec）都在第 1 级。每个演示实现一个 pg.Demo，照这个顺序往下加就行。

模块标签： core shapes textures text audio models shaders raygui
第 1 级
★
打地基
开窗 + 基础图元
core ① 开窗主循环 InitWindow / WindowShouldClose / BeginDrawing·EndDrawing
shapes ② 画线 已做 DrawLineEx
shapes ③ 画圆 已做 DrawCircleV
shapes ④ 画矩形/三角 已做 DrawRectangleRec
core ⑤ 清屏 / FPS ClearBackground / GetFPS
第 2 级
★★
玩结构
坐标 + 文字 + 输入
core ⑥ 结构体 Vector2 / Rectangle / Color 怎么用
text ⑦ 画文字 DrawText / DrawTextEx / MeasureTextEx
core ⑧ 键盘输入 IsKeyDown / IsKeyPressed
core ⑨ 鼠标输入 GetMousePosition / IsMouseButtonPressed
第 3 级
★★★
会动
纹理 + 动画 + 碰撞
textures ⑩ 贴图 LoadTexture / DrawTexture
core ⑪ 动起来 用 Demo.update 做每帧移动
shapes ⑫ 碰撞检测 CheckCollisionRecs / CheckCollisionCircles
core ⑬ 键盘控制小球 输入 + 动画 + 边界反弹（综合）
第 4 级
★★★★
有声有色
音频 + 计时 + 随机
audio ⑭ 音频初始化 InitAudioDevice / LoadSound / PlaySound
audio ⑮ 背景音乐 LoadMusicStream / UpdateMusicStream
core ⑯ 计时与随机 GetFrameTime / GetRandomValue
core ⑰ 简单粒子 多对象数组 + 随机运动
第 5 级
★★★★★
立体
3D 相机与模型
models ⑱ 3D 相机 Camera3D / BeginMode3D·EndMode3D
models ⑲ 3D 图元 DrawCube / DrawSphere
models ⑳ 载入模型 LoadModel / DrawModel
models ㉑ 第一人称视角 UpdateCamera 跟着走
第 6 级
★★★★★★
成瘾
着色器 + UI + 做游戏
shaders ㉒ 着色器 LoadShader / BeginShaderMode
raygui ㉓ UI 控件 你现在的参数面板就是它
综合 ㉔ 整合成小游戏 碰撞 + 得分 + 场景 + 重开

提示：想在教学窗口里看到"按难度排序"，就给 Demo 加个 difficulty 字段，把 demos 数组按它排一下，左侧列表就自动从易到难了。示意图，非 raylib 官方课程。
